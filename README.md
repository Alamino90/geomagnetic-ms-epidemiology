# geomagnetic-ms-epidemiology
An ecological study examining the relationship between geomagnetic cutoff rigidity (cosmic-ray shielding) and global Multiple Sclerosis prevalence.

- **Data Source Details**

Country-level Multiple Sclerosis (MS) prevalence data used in this study were extracted from the global epidemiology map published by the MS International Federation on the [Atlas of MS](https://atlasofms.org/map/global/epidemiology/number-of-people-with-ms). This dataset provides standardized, country-by-country epidemiological estimates—including overall prevalence per 100,000 population and estimated total case counts—enabling global spatial correlation against modeled geomagnetic cutoff rigidity values.
